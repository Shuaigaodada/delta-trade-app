# delta-trade-app — code-only migration backup

This branch is a source-only backup created during the 2026-10-14 project migration.
The local project directory is `D:\Projects\delta-trade-app`.

The backup includes Python source and developer tools, pinned requirements, this scope note, the original MIT
license and Python ignore rules. Test account identifiers use synthetic placeholders.

It excludes the original Git history, API keys/tokens, account or financial data, runtime logs, screenshots and static image assets, dependency environments,
build outputs and caches. No third-party binaries or model files are included.

The complete original Git history and working data remain in the retained local
project and its original repository branches. This new backup branch starts with
one root commit and does not replace `main` or any existing branch. It is **not a
complete runnable application backup**: required runtime data/assets and dependencies
must be restored separately from the retained local project.

No workflow or deployment configuration is included. No live game action, account
login, external application API call or OCR model download was run to create this backup.
